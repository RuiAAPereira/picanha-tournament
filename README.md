# Picanha Tournament

Aplicação local para gerir torneios de pool português. A interface está em desenvolvimento.

## Desenvolvimento

```sh
npm install
npm run dev
```

Testes e verificação de tipos: `npm test` e `npm run typecheck`.
O executável Windows é compilado com `npm run tauri build` num ambiente com Rust e os pré-requisitos do Tauri 2.
